# Mente Brilhante GPT

Landing page responsiva e campanha digital para apresentar a obra **Mentes Brilhantes**, de Alberto Del’Isola.

## O projeto inclui
- `index.html`: página de apresentação responsiva para desktop e celular.
- `assets/`: quatro peças visuais vetoriais em SVG, otimizadas para web.
- `favicon.svg`: ícone personalizado do site.
- `materiais-divulgacao/legendas-sugeridas.md`: textos de divulgação para post e story.
- `.github/workflows/pages.yml`: publicação automática pelo GitHub Pages.

## Publicação
O workflow tenta publicar automaticamente a cada atualização da branch `main`. Confira a aba **Actions** para acompanhar o processo. Na primeira publicação, pode ser necessário abrir **Settings → Pages** e autorizar o GitHub Pages para o repositório.
